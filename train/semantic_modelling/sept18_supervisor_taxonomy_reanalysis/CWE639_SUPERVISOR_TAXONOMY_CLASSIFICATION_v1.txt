CVE=CVE-2020-23449
OUTCOME=DISCRIMINATION_FAILURE
A_ACTUAL_VULNERABILITY_MECHANISM=Newbee-Mall trusted a user identifier supplied through the update request when selecting which user record to modify. The patch instead obtains the authenticated user's identity from the HTTP session and uses that identity to select the update target.
B_QUERY_SECURITY_PROPERTY=A user-controlled request identifier should not flow into an identifier-like parameter of a resource access or modification method.
C_CONCRETE_MISMATCH=The query detects user-controlled identifiers reaching ID-like resource operations, but the actual security property is relational: the target user must be the same user as the authenticated session identity. Generic identifier taint alone cannot express that ownership relation.
NEW_ROOT_CAUSE_CATEGORY=Missing relational/contextual semantics
CATEGORY_RATIONALE=The missing information is the relationship between requested target identity and authenticated session identity.
CONFIDENCE=HIGH
GENERIC_TEMPLATE_COLLAPSE_CANDIDATE=YES
TEMPLATE_COLLAPSE_EVIDENCE=A requester-to-target identity relation is reduced to generic user-controlled-ID taint.
